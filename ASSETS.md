# Asset sources and licenses

Nothing in this project is copied from an existing game. Every asset is either
first-party (generated by scripts in `tools/`) or CC0 from Poly Haven.

| Asset | Source | License | Location |
| --- | --- | --- | --- |
| PBR textures: hangar_concrete_floor, factory_wall, concrete_wall_008, metal_plate, painted_metal_shutter, rusty_metal_grid, rusty_painted_metal, blue_metal_plate, corrugated_iron_02, concrete_floor_painted, green_metal_rust (albedo, normal GL, roughness, AO, ARM, metal) | [Poly Haven](https://polyhaven.com) via its public API | CC0 1.0 | `assets/textures/*` (per-file URLs in `assets/textures/SOURCES.txt`) |
| Weapons (VK-9 carbine, P-12 sidearm), attachments (reflex, 2x prism, suppressor, vertical/angled grips, three magazines), Teslabot, props (crate, drum, server rack, relay console, steel door, caged lamp, jersey barrier, locker, desk, pipe, breaker panel) | Original. Generated by `tools/build_models.py` in Blender 5.3 (headless) | First-party, project-owned | `assets/models/*.glb` |
| All sound effects (rifle/pistol shots plain and suppressed, mechanical reload foley, impacts, ricochet, tesla charge/discharge, robot servos/steps/alert/death, doors, UI, ambience) | Original. Deterministic DSP synthesis in `tools/synth_audio.py` (Python stdlib, fixed seeds) | First-party, project-owned | `assets/audio/*.wav` |
| Level geometry, lighting, particles, lightning, decals, HUD, shaders | Original code in `scripts/` | First-party | — |
| UI font | Bahnschrift (falls back to Segoe UI/Arial) used via the OS `SystemFont`; not redistributed | Ships with Windows | — |
| Engine | Godot Engine 4.7.2 (official build via winget) | MIT | `C:\AAA\tools\godot` (outside the project) |

Kenney CC0 sound packs were considered, but their download links are not
fetchable by script, so all audio is synthesized instead.

Rebuild generated assets:

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.3\blender.exe" -b --factory-startup -P tools/build_models.py -- assets/models
python -I tools/synth_audio.py assets/audio
```
